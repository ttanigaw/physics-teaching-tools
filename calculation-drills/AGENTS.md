# AGENTS.md — calculation-drills

このファイルは `calculation-drills/` 以下の作業に適用する、Codex等の開発エージェント向け指示です。詳しい教育方針は `design/` 内の文書を正本として参照してください。

## 作業範囲と開発方法

- 原則として **`calculation-drills/` の中だけ**を変更する。既存の `motion-graph/` に手を加えない。
- 開発ブランチは `develop/calculation-drills`。ユーザーの了承なく `main` へマージしない。
- すべての技能やCBTの完成を待たず、品質確認済みのモジュールを段階的に公開できるよう構成する。
- 全体分類と仕様は暫定。実装・授業で問題が見つかったら設計文書と問題の両方を更新する。分類IDの変更は既存問題との対応を確認する。
- 新しい大きな依存関係、プラットフォーム、個人情報保存、ライセンス変更、外部公開の判断はユーザーに確認する。
- 作業完了時に変更ファイル、確認結果、未解決事項を明示する。

## 教材の必須原則

- **発見**：工夫の名称や正解への手順を、発見型の学生用問題文・見出しから不用意に明かさない。
- **計算負担の落差**：工夫しないと面倒だが、工夫すると劇的に簡単になる例を意図的に設計する。ただし無意味な負荷を長引かせない。作問時は、筆算の回数・中間数値の桁数・小数や分数の処理負担などを比較し、工夫する価値を確認する（厳密な点数化は現段階では不要）。
- **学習上の障壁の区別**：構造に気づかない／必要な知識がない／知っていても使わない、という違いを考慮して、発見・基礎練習・自発的選択の練習を使い分ける。
- **位置に依存しない習得**：同じ構造を位置・順序・数値・項数を変えて繰り返し、固定配置→混合配置→複合問題へ進める。一度に変える難しさを制御する。
- **前提技能の細分化**：A2では基本の数の組（F1=2×5／F2=25×4／F3=125×8）、倍率（A=基本形／B=10の正の整数冪倍／C=10の負の整数冪倍）、位置と向き（P）、**独立した分解操作（D0/D1/D2/DB）**、方略の実行を区別する。倍率変更のみは分解としない。FとDを同時に難しくせず、必要なら前提技能へ戻れる問題構造にする。
- **将来の適応型CBT/CBD**：単なる正答率だけではなく、下位技能ごとの回答傾向・ヒント・自己修正などから弱点を**仮説として**推定し、次問や支援を変えられるよう問題の診断タグを検討する。ただし今はPDF先行、個人ログ収集やアルゴリズム実装は行わない。
- **問題バンク中心**：A2を48問などの固定総数で完成扱いしない。下位技能の習得・診断に必要な複数の数値例を蓄積し、その一部から紙のプリントを構成する。問題バンクの件数と、一人の学習者の出題数を混同しない。
- **全技能に共通する問題IDの思想**：A2だけでなく、今後のA1・A4・B・C・Rなどにも**数学的構造と独立な診断要素が読める分類型ID**を付ける。各軸のコードをできるだけ短く・長さのばらつきを抑え、重複した情報をIDに持たせない。末尾の`-NN`（2桁連番）だけが同じ詳細パターン内の別数値問題を区別する。**各技能に必要な軸は個別に決め、A2のF/P/Dを一律に流用しない**。命名前に [DESIGN](design/DESIGN.md) を確認する。
- **A2固有の命名**：`A2-F1A-N3P13-D0-01` の形とする。Fで系列・倍率、Pで配置・向き、Dで分解なし／Pの第1因子／第2因子／両方を示す。F1Bに20×5と2×50の両方を含め、倍率をかけた因子を追加コードで区別しない。L/M・難易度・掲載順・細かな倍率などはメタデータに分離。ID/式の重複と旧ID→新IDの対応を検証する（[A2詳細設計](design/A2_MULTIPLICATION_ORDER.md)参照）。
- **自己点検**：答え合わせ前に「あれ？」と気づけるよう、概算・範囲・桁・符号・逆演算・別経路などの手がかりを設計する。ヒントの提示時機は発見の妨げにならないようにする。
- **正しい答案だけを評価しない**：工夫の利用、初回結果、自己修正、確信度の観察も検討する。ただし全問で煩雑な記録を強要しない。
- **正確性**：すべての正答・同値変形・定義域・符号・近似精度を検証する。平方根は特に `sqrt(a^2)=|a|`、根号の積商の条件、近い数の差の近似誤差に注意する。
- **配布物の分離**：学生用、解答・解説、教員用の説明を分ける。発見型の学生用紙面に教師向けの種明かしを混ぜない。

## 成果物を追加するときの検証

- 数学的な正答と想定する効率的解法を、可能なら独立な方法でも確認する。
- 配置別の出題が意図したパターンを満たすか確認する。3数の2数選択は3通り、4数は6通り。
- 問題を解くための新しい技能が不意に混ざっていないか確認する。
- 誤答を誘発すること自体ではなく、自己点検で検出しやすい手がかりがあるか確認する。
- 印刷物では余白、文字サイズ、書き込み空間、解答の漏出がないか点検する。
- 公開リポジトリに、個人情報・学生の個別記録・非公開試験問題・秘密情報を追加しない。
