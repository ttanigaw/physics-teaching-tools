# A4 計算ドリル：試作PDF（v0.5）

A4問題バンク388問（H0が292問、H1が96問）から**H0を71問・H1を9問選んだ学生用10ページ、解答・解説10ページ、教員用メモ2ページ**の試作です。各ページは独立配布できます。数学的な正答と共通因子の位置を確認していますが、学習効果の実測はまだです。

**H1の混合出題（v0.5）**：導入の1〜3ページはH0のみ。4〜10ページは7・8問目にH1をそれぞれ1〜2問配置し、**合計9問（全80問の11.25%）**としました。学生用にはH1の分類や存在を明かしません。N2→N3の段階とS1の全24問（初めの5ページは8問中3問）も維持しています。

**出題構成の改訂（v0.4）**：N2の減算S1だけの1ページを廃止。**第1〜5ページは各8問中3問をS1（37.5%）**にし、初回からS0とS1を混ぜました。3項は「2項だけに共通因子」→「3項全部」の順序を維持。全体でS1は24/80問（30%）。以前作成したv0.3のPDFは旧出題順なので、生成ソースで再生成してください。

`calculation-drills/`から：

```bash
python -m pip install reportlab
node tools/make_a4_pdf_records.mjs
python printable/build_a4_sample.py \
  --records printable/a4_sample_records.tsv \
  --out printable/generated
```

生成ファイル名：
- `a4_sample_student.pdf`
- `a4_sample_answers.pdf`
- `a4_sample_teacher.pdf`

学生用には「共通因子でくくりなさい」「R0」などの解法の種明かしをしません。答え用には共通因子を用いた代表的な変形を記載し、別解を許容します。最終ページで初回答案と見直し後を分けます。**印刷用TSVには符号欄と2倍係数欄を設け、H1の`a×(2×b+c)`型の変形も独立に照合します。**

**PDFは試作品として会話で提供し、GitHubには再生成するためのJSON・TSV・スクリプトを登録**します。正式公開時のPDF保存方法は別途決めます。
