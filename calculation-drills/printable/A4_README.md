# A4 計算ドリル：試作PDF（v0.4）

A4問題バンク388問（H0が292問、H1が96問）の**H0から80問を選択した学生用10ページ、解答・解説10ページ、教員用メモ2ページ**の試作です。各ページは独立配布できます。数学的な正答と共通因子の位置を確認していますが、学習効果の実測はまだです。

| ページ | ねらい | 問題数 |
|---|---|---:|
| 1 | 2項・共通因子の発見（S0=5問／S1=3問） | 8 |
| 2 | 共通因子の位置 P11/P12/P21/P22 の混合（S0=5／S1=3） | 8 |
| 3 | L43/L44・計算負荷の軽減（S0=5／S1=3） | 8 |
| 4 | R1/R2のボーナス（S0=5／S1=3） | 8 |
| 5 | A4×A2の複合5問とS1の対照3問 | 8 |
| 6 | 3項中2項に共通因子・L33 | 8 |
| 7 | 3項中2項に共通因子・L44 | 8 |
| 8 | 3項すべてに共通因子・S0/S1混合 | 8 |
| 9 | 3項すべてに共通因子・S0/S1/S2混合と桁縮約 | 8 |
| 10 | 2項・3項、加減算の混合と自己点検 | 8 |

**H1追加の扱い**：L22・因子比2倍のH1問題をN2/N3に96問追加しましたが、**現在のv0.4試作PDFの80問にはまだ採用していません**。出題プランとPDF生成スクリプトは変更していません。

**出題構成の改訂（v0.4）**：N2の減算S1だけの1ページを廃止。**第1〜5ページは各8問中3問をS1（37.5%）**にし、初回からS0とS1を混ぜました。3項は「2項だけに共通因子」→「3項全部」の順序を維持。全体でS1は24/80問（30%）。以前作成したv0.3のPDFは旧出題順なので、生成ソースで再生成してください。

`calculation-drills/`から：

```bash
python -m pip install reportlab
node tools/make_a4_pdf_records.mjs
python printable/build_a4_sample.py \
  --records printable/a4_sample_records.tsv \
  --out printable/generated
```

生成ファイル名：
- `a4_sample_student.pdf`
- `a4_sample_answers.pdf`
- `a4_sample_teacher.pdf`

学生用には「共通因子でくくりなさい」「R0」などの解法の種明かしをしません。答え用には共通因子を用いた代表的な変形を記載し、別解を許容します。最終ページで初回答案と見直し後を分けます。**印刷用TSVは符号欄を含み、元の数式と計算結果の整合性を確認します。**

**PDFは試作品として会話で提供し、GitHubには再生成するためのJSON・TSV・スクリプトを登録**します。正式公開時のPDF保存方法は別途決めます。
