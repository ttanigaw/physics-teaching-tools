# A2 プリント試作

**試作中／未検証**。問題バンクを共通の正本とし、選択プランから学生用・解答解説用・教員向けメモの3種類のPDFを生成する。

| ファイル | 内容 |
|---|---|
| [a2_sample_plan.json](a2_sample_plan.json) | 試作11セット、計110問の問題IDと順序・指導意図 |
| [build_a2_sample.py](build_a2_sample.py) | A4 PDF 3種を再現可能に生成するスクリプト |

## 生成コマンド

`calculation-drills/`をカレントディレクトリとして実行する：

```bash
python -m pip install reportlab
python printable/build_a2_sample.py \
  --bank problems/a2_bank.json \
  --plan printable/a2_sample_plan.json \
  --out printable/generated
```

出力：
- `a2_sample_student.pdf`（11ページ、学生用：分類・解法は表示しない）
- `a2_sample_answers.pdf`（11ページ、解答・解説。2因子・分解なしは解答のみ）
- `a2_sample_teacher.pdf`（2ページ、教員用メモ・各セットの指導意図）

生成PDFは実行環境の `printable/generated/` に置く。**今はGitHubには生成ソースを登録し、PDF自体は試作品として会話に添付**する。後日正式公開する際のPDF配布方法は別途決める。

## 試作セットの構成

1. 2因子・基礎確認（10問。九九のみの独立問題なし）
2. **2因子・分解あり（8問）**。数の分解を独立に練習し、最終解答が偏らないよう数値違い5問を追加
3. 3因子・工夫の発見（8問）
4. 3・4因子・位置と向きの混合（12問）
5. F2C・3因子（12問）
6. F2C・4因子（12問）
7. F3C・3因子（12問）
8. F3C・4因子（12問）
9. F2C/F3C・3/4因子の混合（12問）
10. 3因子の分解、複数の有利な組、対照問題（8問）
11. 初回答案と見直し後を分ける自己点検（4問）

**解答解説の記述原則**：2因子・D0では計算順序を選ぶ余地がないため、原則として正答だけを示す。2因子・D1/D2/DBは必要な分解の着眼点を示すが「先に～を計算」とは書かない。3因子以上で順序の工夫がある場合に限り、先に組み合わせる因子を解説する。冗長な自明の解説は避ける。

**全員に110問を必ず課す設計ではない**。11ページは必要な段階だけを選んで配布できるよう1セット1ページで構成した。F2C/F3Cの追加分は位置・向き・小数の組の種類を混ぜつつ、最初は同じF系列・同じ因子数で練習し、その後に混合する。短いセットとして分割し、授業の段階や個々の前提技能に合わせて利用する。発見型の学生用紙面では解法の名称を先に示さない。授業前に数式・解答・難易度・記入欄を教員が再確認すること。
