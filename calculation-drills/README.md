# 計算の工夫と自己点検を育てるドリル

> 開発中・構想 v0.1。完成した教材から段階的に公開します。

## 目的

物理の計算で、与えられた式を機械的に左から処理するのではなく、式の構造を観察し、効率的な計算方法を選び、答え合わせの前に誤りの可能性に自ら気づけるようになることを目指します。

育成する能力は次の3つです。

- **発見・探索**：煩雑な計算の中に、簡単になる構造を見つける。
- **計算最適化**：順序変更、約分、因数分解、数の表現、平方根の扱いなどを使う。
- **自己監視・修正**：概算、範囲、符号、逆算などを使って、正答を見る前に計算を点検する。

正答率だけでなく、**最初に気づかなかった工夫を途中で発見したこと**、**初回誤答を自分で修正したこと**も重視します。

## 教材開発の方針

1. **プリント（PDF）を先行**し、学生用・解答解説・教員用資料を制作する。
2. **一つの工夫から始め**、因子や項の位置、数値、項数を変えて認識を一般化する。
3. **発見型の問題**では、工夫しないと煩雑だが工夫すれば簡単になる体験を設計する。初めから解法を教えすぎない。
4. **メタ認知の手がかり**を組み込む。計算前の予測、結果の妥当性確認、答え合わせ前の自己修正など。
5. **完成した部分から公開**する。全体分類は暫定的で、実際の教材制作・授業利用を通じて更新する。
6. 問題の内容と印刷・Webでの表示を、できる範囲で分離する。**問題バンクの各問題には、下位技能や数の組・配置などの一意なIDと診断情報を持たせる。** 将来は適応型のCBT/CBD（GitHub Pagesを想定）で苦手な部分に応じて出題を変え、必要に応じて学習進度管理を検討する。

## 現時点の優先対象

- **A2：乗算順序の工夫**（3数の全3配置、4数の全6配置、混合、複数の有利な組）。
- **A4：分配法則の逆利用**（共通因子が前・後・混在する4配置、混合、複数項）。
