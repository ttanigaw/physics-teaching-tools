# A2詳細設計 — 掛け算の順序を工夫する

状態：**詳細設計の初稿 v0.1／教材未完成**。対象は算術の積の交換法則・結合法則。ここでは「問題の学習上の役割・配列・採否基準」を定め、学生用プリント・完成問題集は次工程で作る。

上位方針：[CONCEPT](CONCEPT.md)／[DESIGN](DESIGN.md)／[ASSESSMENT](ASSESSMENT.md)／[SKILLS](SKILLS.md)

## 1. 学習目標と到達行動

- **G1：発見・探索**。数の並びを眺め、自然な左から順の計算に固執せず、先に掛けるとよい2数を見つける。
- **G2：計算最適化**。交換法則・結合法則を使い、25×4=100、125×8=1000、20×5=100 などを利用して計算量を減らす。
- **G3：自己監視・修正**。計算前後の桁・概算・末尾の0の個数・別の括り方などで、解答を見る前に疑問を持ち、必要なら修正する。
- **転移目標**。有利な2数がどの位置にあっても、また「特別な有利な組がない」ときも、計算方法を選び直せる。

**重要な区別**：(1,2) に有利な組がある問題は、左から計算すればすでに効率的な場合がある。「位置網羅」に必要だが、必ずしも「順序変更の発見」を促す問題ではない。複合問題・対照問題として位置づけ、発見型の中心にはしない。

## 1.1 有利な2数の積自体にも前提技能がある

例えば `25×37×4` で25と4を選択できても、`25×4=100` をすぐに計算できなければ工夫の効果を実感しにくい。**数の組の計算**、**有利な組の認識**、**実際の順序変更**を別の到達目標・診断対象にする。

### F：有利な数の組の習熟難度（仮の進行）

| 段階 | 数の組（逆順も必ず扱う） | ねらい |
|---|---|---|
| F1 | 2×5、5×2 | 10になる基本的な組を確実に扱う |
| F2 | 20×5、5×20、2×50、50×2 | 10の倍数へ拡張し、100をつくる |
| F3 | 25×4、4×25 | 100になる別の組。必要なら25×2=50、50×2=100を経由する |
| F4 | 125×8、8×125 | 1000になる組。必要なら125→250→500→1000の倍々を経由する |
| F5（発展） | 2.5×4、0.25×4、0.125×8など | 小数の数表現と関連。C系列との重なりを明示する |
| F6（発展） | 25×12、125×24など | 数を分解して有利な組を作る。単なる位置探索を超える |

F1〜F4の順は**初期仮説であり、学生の実態により調整する**。F1をすでに習得した学生には、機械的な全問反復を求めない。F5・F6は前提知識が増えるため、初期プリントへ無理に含めない。

A2では少なくとも次を区別する。

1. **F（数の組の計算）**：`25×4` 単独を計算できるか。
2. **P（組の発見）**：`25×37×4` から25と4を見いだせるか。
3. **O（方略の選択・実行）**：見つけた2数を先に掛け、全体を正しく計算できるか。

これらに**M（検算・違和感検出）**が重なる。正しい最終答えだけから、どの能力を使えたか断定しない。

**紙の教材への含意**：先行する短い2数の練習・確認（A2-0）を設ける余地を残す。発見型の本編は、数の組を十分に扱える段階で実施するか、必要に応じて支援する。FとPを同時に難しくすると、つまずきの原因を特定できなくなる。

## 2. 問題設計の軸と制約

| 軸 | 本モジュールでの変化 |
|---|---|
| P：配置 | 3数の P12/P13/P23、4数の P12/P13/P14/P23/P24/P34（以下、1始まりの位置） |
| N：因子数 | 3数→4数→2組の有利な組、必要なら5数以上 |
| V：数値 | 因子全体の大きさや種類。まず整数のみ、小数は発展に回す |
| F：有利な組自体の難度 | 2×5 → 20×5／2×50 → 25×4 → 125×8 を目安にし、逆順も扱う |
| K：技能 | 導入は A2 単独。小数の分数化（C1）・約分（A1）等は後の複合問題で扱う |
| D：探索難度 | 位置固定→混在→複数の有利な組→見かけ上有利な組がない対照問題 |

初期の問題は**「有利な組」を1組だけ明瞭に配置**し、他の組合せに同程度に目立つ近道がないか確認する。ただし数学的に唯一の最適経路を強制しない。計算しやすさは学習者に依存するため「代表的な短い解法」と記録する。

初期は整数・正数で統一し、負号、小数、分数、指数、根号、乗除混合は新たな技能を要求し得るので分離する。工夫しない方法が簡単すぎる問題は発見型に置かず、対照・選択問題で活用する。

## 3. 配置の完全な網羅

### 3.1 3数（3通り）

| 配置 | 有利な組の位置 | 代表例 | 正答 | 役割 |
|---|---|---|---:|---|
| P13 | (1,3) | 25×37×4 | 3700 | 最初に発見を促す。離れた数を結びつける |
| P23 | (2,3) | 41×25×4 | 4100 | 最初の数をいったん飛ばして後ろをまとめる |
| P12 | (1,2) | 25×4×61 | 6100 | 左からでもよいと判断する／位置の偏りをなくす |

導入順は **P13 固定→P23 固定→P12 を含む三配置の混合**。後半は (1,2)→(2,3)→(1,3) と予測可能な周期にならないよう、各配置の出現回数を揃えた上で順番を変える。

### 3.2 4数（6通り）

| 配置 | 有利な組の位置 | 代表例 | 正答 |
|---|---|---|---:|
| P12 | (1,2) | 25×4×17×13 | 22100 |
| P13 | (1,3) | 125×17×8×3 | 51000 |
| P14 | (1,4) | 20×17×3×5 | 5100 |
| P23 | (2,3) | 19×25×4×7 | 13300 |
| P24 | (2,4) | 23×20×7×5 | 16100 |
| P34 | (3,4) | 29×3×125×8 | 87000 |

各配置を認識しやすい問題で紹介し、その後 **全6配置×2問以上を混合**する。隣接ペア P12/P23/P34 と非隣接ペア P13/P14/P24 がともに扱われるようにする。P12 は計算の組み直しが必須ではない対照例にもなる。

### 3.3 2組の有利な組・工夫不要問題

| 種別 | 代表例 | 代表的な方略 | 正答 |
|---|---|---|---:|
| 2組 | 25×8×4×125 | (25×4)(8×125) | 100000 |
| 2組 | 20×25×5×4 | (20×5)(25×4) | 10000 |
| 対照・3数 | 13×17×19 | 目立った100・1000になる組はない | 4199 |
| 対照・4数 | 11×17×23×3 | 目立った100・1000になる組はない | 12903 |

「工夫が不要」は**何も工夫できない**という意味ではなく、このモジュールで狙うきりのよい積を作る特別な組合せが見つからない例を指す。たとえば 13×17×19 にも人によって異なる計算方法はある。解法の押しつけではなく適切な選択を評価する。

## 4.1 問題を確定する際のF×P分離

初稿の候補にはF3・F4に相当する問題が多いが、**導入から25×4や125×8を暗算できることを前提としない**。単独の2数の計算確認（F）を設けた上で、位置固定（P13等）と混合（P12/P13/P23）に進める。数の組の難度を上げるときは配置をなるべく固定し、配置を変えるときは習得済みの数の組を使う。

## 5. 学習ブロックの仮設計（全48問程度、調整可）

問題数は**試作のための仮配分**。1枚で48問を一気に解かせる前提ではない。複数の短いプリントや授業内の区切りに分けられるようにする。**A2-0（2数の組の習熟確認・補充練習）は現行48問に含まれていない**ため、次の試作で問題数・配分を見直す。

| ブロック | 形式 | 目安 | 主なねらい |
|---|---|---:|---|
| I | L1：P13固定・3数 | 5 | 面倒な計算を通じて最初の工夫を発見。解法は先に知らせない |
| II | L2/L3：P23固定・3数 | 4 | 他の位置でも同じ発想が使える |
| III | L3：3数のP12/P13/P23混合 | 9（各3） | 位置を予測せず毎回探索。P12は対照としても使う |
| IV | L2/L3：4数の全6配置 | 12（各2） | まず6配置を確認し、その後順序を混在 |
| V | L3/L5：3・4数の混合 | 12 | 2組同時、工夫不要、組の種類の変化を含む |
| VI | L4/L5：自己点検・確認 | 6 | 初回答案→自力点検→修正、独立した検証、簡潔な振り返り |
| **合計** | | **48** | あくまで初稿の試算 |

I の5問で発見に至らない場合も失敗扱いにしない。解法を見せる前の観察を優先しつつ、行き詰まりが続く場合にはヒントを段階的に提示する。II〜IVは支援後に先へ進んでもよい。

### 出題順と混合の規則

- 固定配置のブロックは導入として意図的に連続させるが、混合ブロックは**位置コードの並びが規則的にならない**ようにする。
- 同じ数値（25×4）だけを繰り返しすぎず、125×8、20×5、50×2などの複数の数値関係を混ぜる。なお数値の種類まで同時に増やすタイミングは調整する。
- 同じ答えを暗記して当てられないよう、隣接問題で因子集合・答えの使い回しを避ける。
- 工夫不要の対照問題は導入では避け、工夫の存在を前提に思い込まなくなってほしい段階で混ぜる。
- 完全な乱数配列より、**各配置の出題数を制御した擬似ランダムな配列**を優先する。将来CBTでは再現可能な出題シードを検討できる。

## 6. L1「発見型」の具体的な授業内フロー

1. 学生用には「計算してください」程度の指示だけを示す。題名で「順序を変えよう」と教えない。
2. まず各自で解き、必要なら途中式を残す。発見した問題に本人が小さく印を付けられるようにする（初回から印の意味を過度に指示しない）。
3. 途中で「もっと簡単な計算がある」と自発的に気づいたら、同じ見方が次の問題にも使えるか試す。
4. 様子を見て段階的な支援を入れる（例：①計算の順序は必ず左からか？ ②先に掛けると簡単になる2数がないか？ ③代表例の解法を比較）。**数問後の強制ヒントを固定しない**。
5. 発見後、非効率な方法との負担の違いを短く振り返る。その後は見た目や位置を変えた問題に進む。

「未発見」の状態を長く引き延ばすことは目的ではない。計算技能を既に身につけている学生が、初問から効率的に解く場合も正当に扱う。

## 7. G3：自己点検と記録

導入直後に「100になる組を探せ」と予測させると、解法を先取りする可能性がある。初期のL1では点検のヒントを抑え、**発見後のL4**で検算・数量感覚を明示的に扱う。

| 検証の観点 | A2での具体例 | 留意点 |
|---|---|---|
| 概算・桁（M1/M8） | 25×37×4 は数千程度 | 概算は正答の代用ではない |
| 末尾の0・倍数（M4/M7） | 25×4×37 は100の倍数 | 組を事前に示すと種明かしになる |
| 別の括り方（M6） | (25×4)×37 と 25×(4×37) の照合 | 毎回両方の筆算は不要 |
| 逆算（M5） | 結果を4等分して25×37と比べる | 逆算そのものが煩雑な場合は使わない |

**紙での最小記録案**：通常の計算欄に加え、選択した一部の問題だけ「初回の答え」「見直し後の答え」「途中で方法を変えた／誤りに気づいた」の印を入れる。正答を見る前の修正と、解答公開後の修正を区別する。確信度の記録は全問必須としない。

**他者の答案を判定する問題**では、誤りを含む式と正しい式を混ぜ、なぜ判定したかを短く説明させる。結果だけでなく、桁・末尾・計算構造からの違和感を促す。

## 7.1 将来のCBT/CBD：下位技能を診断する適応型ドリル

紙のPDFを当面の主教材とする一方、**CBT（Computer Based Testing）／CBD（Computer Based Drill）では、解答履歴をもとに個々の苦手部分を推定し、次の出題と支援を調整する**ことを将来要件とする。A2だけでもF・P・O・Mが異なるため、モジュール単位の「できる／できない」で判断しない。

| 観察した結果（例） | 疑う弱点 | 次に提示する診断・練習の候補 |
|---|---|---|
| 25×4単独が不正解 | F：数の組の計算 | 4×25、25×2→50×2など。必要ならF2へ戻る |
| 2数は正解、3数では有利な組を選べない | P：組の認識・位置探索 | 習得済みFのままP13固定→P23→混合 |
| 組は選べるが全体の答えが不正解 | O：方略の実行または別の算術 | 選択した組の積、残りの掛け算を分離して確認 |
| 特定の配置のみ誤る | 位置への依存 | 同じFを保ち、苦手な配置を重点的に提示 |
| 答えがおかしくても修正できない | M：自己点検 | 桁・末尾の0・別の括り方による検証練習 |

これは**仮説に基づく次の問題選択**であり、単問の正誤で弱点を確定しない。同じ技能の複数の問題や異なる数値・配置で再確認し、誤答の偶然性と学習者の複数の正しい解法を考慮する。

- 最終答案の正誤だけではF/P/Oを区別しにくい。必要に応じて「まず2数の積」「先に掛ける2数の選択」「計算結果」のように**観察対象を切り分ける短問**を使う。
- ただし発見型L1の冒頭から「先に掛ける2数を選べ」と表示すると種明かしになる。診断用の明示的な問いは、発見段階の後または必要な支援の段階で提示する。
- 将来の選択ロジック例：**短い診断→弱点の仮説→対応する数問→再診断→先へ進む／支援を変える**。正答・誤答の傾向、ヒント利用、初回回答から自己修正までを参照する。反応時間は補助情報に留める。
- 出題を適応化しても、既習の配置や数値を時々混ぜて**転移・保持を確認**する。得意な技能だけを出し続けたり、同じ問題の記憶だけで正答できるようにしない。
- この段階では診断規則・閾値・技術構成・個人ログ保存方式は**未決定**。個人情報は公開リポジトリに保存しない。

## 8. 作問・採用・公開の品質ゲート

### 8.1 各問題で確認すること

- 正答が厳密に正しいか、代表的な短い解法が成立するか。
- 想定する有利な組の位置が正しく記録されているか。異なる組にも予期しない「近道」がないか（あれば複数解法として記録）。
- **工夫しない場合と工夫した場合の落差**：筆算回数、中間数値の桁、暗算しやすさを比較したか。
- その問題で新しく必要になる知識がないか。初期は整数の積のみにする。**F（2数の積の習熟難度）とP（配置）を別々に記録**し、両方を不用意に同時に上げない。
- 解法を知らなくても使える自己点検の手がかりがあるか。なくても「発見型」等の目的に照らして採否を決める。
- 問題の見出し、連番、並び順、例示によって先に方法が漏れていないか。
- 学生の効率的な別解や、左から計算した方が自然な場合も許容しているか。

### 8.2 ブロック・教材全体で確認すること

- 3数の3配置、4数の6配置が、固定→混合という学習順に沿ってカバーされているか。
- 出題数の偏りと、連続する問題の数値・解答の重複を確認したか。
- L1とL2を混同せず、発見の余地・適切な支援・定着練習の双方があるか。
- L4では正答提示前の自己点検が可能か。別解法を強制して過剰負担にしていないか。
- 学生用・解答解説用・教員用を分離し、印刷しやすい紙面と十分な計算欄を用意しているか。

## 9. 次工程（STEP 4）への受け渡し

1. 仮48問の**F×配置×学習形式の出題マトリクス**を見直し、A2-0の数の組の練習を追加するか決め、候補を補充する。現時点の代表例だけでは完成問題セットではない。
2. 各問題に安定した問題ID、正答、少なくとも1つの効率的解法、主な誤答、自己点検の観点を付ける。
3. 学生用・解答解説用・教員用を分けた印刷原稿を試作する。
4. 全問題の正答と配置コードを検査し、PDFの数式・余白・印刷品質を確認する。
5. 可能なら学生による試用を通じて、想定した発見順や難易度を見直す。

現時点でPDF作成方法、YAML/JSON等のデータ形式、評価欄の最終レイアウトは固定しない。設計を優先し、試作結果に合わせて選択する。
