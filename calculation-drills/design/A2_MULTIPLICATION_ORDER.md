## 1. 学習目標と到達行動

- **G1：発見・探索**。数の並びを眺め、自然な左から順の計算に固執せず、先に掛けるとよい2数を見つける。
- **G2：計算最適化**。交換法則・結合法則を使い、25×4=100、125×8=1000、20×5=100 などを利用して計算量を減らす。
- **G3：自己監視・修正**。計算前後の桁・概算・末尾の0の個数・別の括り方などで、解答を見る前に疑問を持ち、必要なら修正する。
- **転移目標**。有利な2数がどの位置にあっても、また「特別な有利な組がない」ときも、計算方法を選び直せる。

**重要な区別**：(1,2) に有利な組がある問題は、左から計算すればすでに効率的な場合がある。「位置網羅」に必要だが、必ずしも「順序変更の発見」を促す問題ではない。複合問題・対照問題として位置づけ、発見型の中心にはしない。

### 1.1 有利な2数の積自体にも前提技能がある

例えば `25×37×4` で25と4を選択できても、`25×4=100` をすぐに計算できなければ工夫の効果を実感しにくい。**数の組の計算**、**有利な組の認識**、**実際の順序変更**を別の到達目標・診断対象にする。

### F：数の組の基本系列と10のべき乗倍率

Fコードは **3文字の `F{系列}{倍率}`** とし、異なる種類の情報を混同しない。

| 系列 | A：基本形 | B：10倍・100倍など | C：1/10倍・1/100倍など |
|---|---|---|---|
| F1 | 2×5 | 20×5、2×50 | 0.2×5、2×0.5 |
| F2 | 25×4 | 250×4、25×40 | 2.5×4、0.25×4 |
| F3 | 125×8 | 1250×8、125×80 | 12.5×8、1.25×8 |

- **A** は基本形、**B** は基本の因子の少なくとも一方を正の整数冪の10倍、**C** は少なくとも一方を10の負の整数冪倍にした形。**B/Cの倍率を与えた因子・10の指数はIDで区別しない**（必要なら問題メタデータへ）。基礎の例では片側の因子だけを倍率変更する。両側に別の倍率変更が混在するなど、B/Cの帰属が曖昧な式は、無理に単一Fに押し込まず設計時に別途検討する。
- 倍率変更だけは「数の分解」とは判定しない。たとえば`20×5`（F1B）、`2×50`（F1B）、`2.5×4`（F2C）は**D0（分解なし）**。
- 主対象は**15〜16歳**であり、`2×5`や`5×2`などの**九九だけで解ける独立した問題は出題しない**。F1Aの`2×5`は分類上の基準として維持するが、それ自体を反復させない。F1Aを用いた3因子以上の順序発見問題（例：`2×91×5`）は残す。
- 基礎確認は原則としてF1B（20×5、2×50等）から始め、F2A・F3Aへ進む。必要に応じてF1C等を扱い、順序は学習者に合わせて調整する。F1C/F2C/F3Cなど小数を含むものは別の前提技能と重なるため、導入時機を検討する。
- 従来の`F2A`（20×5）・`F2B`（2×50）は、どちらも新`F1B`へ統合する。従来の`F3`（25×4）は`F2A`、従来の`F4`（125×8）は`F3A`へ移行する。従来の小数のF5系列は対応するC（例：2.5×4→F2C、0.125×8→F3C）へ移す。

### D：数を分解して基本の組を取り出す操作（旧F6）

旧F6はFの次の段階ではなく、**F1A〜F3Cのどれとでも組み合わせ得る独立軸**とする。たとえば25×4（F2A・D0）と25×12（F2A・D2）は、基本の組が同じで分解の要否が異なる。

| Dコード | 意味（Pで指定した基本系列の因子に対して） | 例 |
|---|---|---|
| D0 | 分解なし | 25×4 |
| D1 | Pの第1位置の因子を分解して必要な因子を取り出す | 26×5 → (2×13)×5 |
| D2 | Pの第2位置の因子を分解して必要な因子を取り出す | 25×12 → 25×(4×3) |
| DB | Pの両位置の因子を分解する | 6×15 → (2×3)×(5×3) |

D1/D2は**式の左から数えた因子1・因子2ではなく、Pコードに書かれた1番目・2番目の位置**を指す。たとえば`N3P32-D2`では式の位置2の因子を分解する。

- `40×5`を`20×2×5`として解く場合、F1Bの20×5を作るための分解なのでD1。一方、`20×5`そのままはF1B・D0。
- 数を一旦分解せず、そのまま10倍・100倍等にしただけならD0。原式に書かれた因子数Nは、あくまで**分解前**のものを数える。
- 基本の組をすでに暗算できることと、分解してその組を取り出せることは異なる。将来の適応型CBDで切り分けて診断する。

A2では少なくとも次を区別する。

1. **F（数の組の計算）**：`25×4` 単独を計算できるか。
2. **P（組の発見）**：`25×37×4` から25と4を見いだせるか。
3. **O（方略の選択・実行）**：見つけた2数を先に掛け、全体を正しく計算できるか。

これらに**M（検算・違和感検出）**が重なる。正しい最終答えだけから、どの能力を使えたか断定しない。

**紙の教材への含意**：先行する短い2数の練習・確認（A2-0）を設ける余地を残す。発見型の本編は、数の組を十分に扱える段階で実施するか、必要に応じて支援する。FとPを同時に難しくすると、つまずきの原因を特定できなくなる。

## 2. 問題設計の軸と制約

| 軸 | 本モジュールでの変化 |
|---|---|
| P：配置・向き | `P13`（基本系列の第1因子が位置1、第2因子が位置3）、逆向きは`P31`。3数は3組×両向き、4数は6組×両向き |
| N：因子数 | 3数→4数→2組の有利な組、必要なら5数以上 |
| V：数値 | 因子全体の大きさや種類。まず整数のみ、小数は発展に回す |
| F：基本の組と倍率 | `F1A`～`F3C`。系列1～3と倍率A/B/Cを独立に扱う |
| D：数の分解操作 | `D0`（なし）、`D1`・`D2`・`DB`（Pの第1／第2／両方）。Fと独立に扱う |
| K：技能 | 導入は A2 単独。小数の分数化（C1）・約分（A1）等は後の複合問題で扱う |
| discovery_difficulty：発見難度 | 位置固定→混在→複数の有利な組→見かけ上有利な組がない対照問題。IDのD（分解）と区別し、メタデータに保持 |

初期の問題は**「有利な組」を1組だけ明瞭に配置**し、他の組合せに同程度に目立つ近道がないか確認する。ただし数学的に唯一の最適経路を強制しない。計算しやすさは学習者に依存するため「代表的な短い解法」と記録する。

初期は整数・正数で統一し、負号、小数、分数、指数、根号、乗除混合は新たな技能を要求し得るので分離する。工夫しない方法が簡単すぎる問題は発見型に置かず、対照・選択問題で活用する。

## 4. 問題IDの命名方針と初期素材

### 4.1 問題IDの構造

**基本形：`A2-F1A-N3P13-D0-01`**

| 部分 | 意味 |
|---|---|
| `A2` | 対象技能 |
| `F1A` | 基本の数の組の系列F1/F2/F3と、倍率A（そのまま）・B（10の正の整数冪倍）・C（10の負の整数冪倍） |
| `N3` | 元の式（分解前）の因子数 |
| `P13` | 基本系列の第1因子が位置1、第2因子が位置3。逆向きは`P31`（AB/BAという別コードは不要） |
| `D0` | 分解なし。`D1`／`D2`／`DB`は、Pに記した第1／第2／両方の位置の因子から、基本の組を作るために分解する |
| `01`～`99` | **同じ構造接頭辞に属する、別の数式を持つ問題の連番**。末尾のハイフンと2桁のみを数値違いに使う |

**F系列の基準**：F1=2×5、F2=25×4、F3=125×8。B/Cの倍率変更は**分解ではないためD0**とする。Bには20×5と2×50の両方を含み、倍率をかけた因子・10の指数はIDで区別しない。必要であれば数値情報を別メタデータに保存する。

**Dコードの基準**：`D1`はPに書いた**最初の位置**、`D2`は**2番目の位置**の因子を分解する。`P32-D2`で分解するのは位置2の因子である。元の因子数が2でも3でも4でも同じ規則を使う。

| 仮ID | 数式 | 設計上の区別 |
|---|---|---|
| `A2-F1B-N2P12-D0-01` | 20×5 | F1の10倍型・分解なし。九九だけの問題は採用しない |
| `A2-F1A-N3P12-D0-03` | 2×5×61 | **同じN3P12-D0接頭辞の3番目**という意味の説明例（実際に01/02の別問題を登録した場合のみ03を発行） |
| `A2-F1B-N3P13-D1-05` | 40×37×5 | F1Bの20×5を利用し、Pの第1位置の40から20を取り出す。**05は説明例** |
| `A2-F2A-N3P32-D2-07` | 17×8×25 | 第1基準因子25が位置3、第2基準因子4に相当する8が位置2。8=4×2。**07は説明例** |
| `A2-F3C-N4P24-DB-09` | 37×25×19×24 | F3Cの12.5×8を利用。位置2の25=12.5×2、位置4の24=8×3と双方を分解する。**09は説明用** |

上表の末尾連番03・05・07・09は命名法を説明する仮の値であり、実際に問題バンクへ登録する際には接頭辞ごとに既登録IDを調べて順番に発行する。F3Cの例では、25=12.5×2、24=8×3という**10のべき乗倍率そのものではない分解**が両側に必要なのでDBに該当する。

**複数組**：位置組をPの記載順で示し、対応するF/Dをアンダースコア区切りで列挙する。例：`A2-F2A_F3A-N4P13_P42-D0_D0-01`（25×8×4×125）。基本組がなければ`A2-F00-N3P00-D0-01`のように対照用コードを使う。

**問題の一意性・管理上の規則**

- 原則としてIDは問題の**構造上の分類**を表す。A2以外でも、主要技能・独立な下位技能・配置／数式構造・操作の有無など、識別すべき軸を定義し、末尾の**2桁連番のみ**を同じ分類内の数値差に用いる。
- **同一構造接頭辞で複数問を発行できる場合にのみ連番が増える**。F1A・N2P12・D0は式が2×5に固定されるが、九九の単独問題なので**出題対象外**とする。一方、F1A・N3P12なら第三因子を変えて数式の構造認識問題を複数作れる。
- 式を掲載するプリントの順序、学習形式L1～L5、自己点検の観点M、難易度、想定誤答、倍率を施した因子や10の指数、分解の細かい形は**IDとは別のメタデータ**で管理する。
- 複数の分類が可能なら、**主たる作問意図による1つのIDを選び**、別解や副次的な技能はメタデータに残す。同一式の二重登録を避ける。
- **登録済みの既存28例**は旧仮ID→新仮IDを一対一で対応させる（4.2、3章参照）。移行規則は「旧F1→F1A、旧F2A/F2B→F1B、旧F3→F2A、旧F4→F3A」、「旧ABのPij→Pij、旧BAのPij→Pji」、「旧DEC0→D0」である。複数組は各組に同じ変換を行う。既存28例では接頭辞の衝突がなく、末尾2桁も維持できる。現在は未公開の仮IDであり、旧形式はGit履歴から参照できる。問題IDを一度配布・参照した後は、黙って付け替えず移行履歴を残す。
- 数式とIDの対応、ID・式の重複に加え、**九九の単独問題が紛れ込まないこと**を作問時に検査する。100件以上同じ接頭辞を要する場合や長大な複合IDの扱いは相談して決める.

### 4.3 問題を確定する際のF×P×Dの分離

## 5. 問題バンクを中心とする設計・配列

### 5.1 固定48問案の撤回

当初の48問案は、主に3数・4数の**位置の網羅**から逆算した試算であり、F1～F3の基本系列と倍率A/B/C、独立したD（数の分解）の有無、逆順、数の組の認識、実行、自己点検、対照問題を扱うには不十分だった。**48問でA2を完成させるという前提は廃止**する。

今後は問題バンクに十分な候補を蓄積し、目的に応じて紙のプリントでは一部を選び、将来のCBT/CBDでは個別の習熟状況に応じて出題する。**問題バンクの収録数と、一人の学習者が解く問題数は別**である。最初から総数の上限を定めない。100〜150問程度という数字は以前の粗い見積もりにすぎず、達成ノルマではない。

### 5.2 問題バンクの網羅軸

| 軸 | 管理・点検する内容 |
|---|---|
| F：2数の組の習熟 | F1/F2/F3の系列とA/B/Cの倍率の組合せ。向きはPに含める |
| D：数の分解 | Fと独立にD0（なし）、D1/D2/DB（あり）を必要に応じて設定 |
| P：位置・向き | 3数の3位置組×2向き、4数の6位置組×2向き。P13とP31を区別 |
| N：因子数 | N2の基礎、N3の発見、N4の混合。N5以上は必要に応じて |
| O：方略実行 | 2数を先に計算して全体を解く／別解の比較／順序変更が不要な場合の判断 |
| M：自己点検 | 概算、桁、末尾の0、逆算、異なる方法による照合、正誤判定 |
| L：学習形式 | 発見（L1）、習得（L2）、転移（L3）、自己点検（L4）、総合（L5） |

**D（旧F6）はFと直交する操作軸であり、数の組の最終段階ではない。全軸の直積を機械的に埋める必要はない**。F1AでもD0／D1を比較できるし、F3までDを待つ必要はない。ただし分解練習の導入時機は学生の前提知識に合わせる。診断・習熟確認に必要な差を作れるセルを優先して、同じ詳細パターンに複数の数値違い（`-01`, `-02` …）を蓄積する。IDのF・P・Dは索引として使い、習熟度、誤答特徴、出題履歴などは別メタデータで管理する。

### 5.2.1 F2C／F3Cの小数の組を見抜く転移練習

15〜16歳の学習者では、`25×4`や`125×8`を知っていても、`2.5×4`、`0.25×4`、`12.5×8`、`0.125×8`などを3因子・4因子の式の中で見抜きにくいことがある。そのため**F2C-N3、F2C-N4、F3C-N3、F3C-N4を重点的に拡充**する。

- 2026-11-21時点で各分類に36問ずつ追加。該当分類は36／36／36／37問（既存のF3C-N4・DBが1問）。
- まずD0（分解不要）に絞り、**小数の組そのものの認識**と**位置・向きが変わっても気づくこと**を練習する。分解D1/D2/DBとの複合は後の段階に分離する。
- N3は6通りの順序付き配置をすべて扱う。N4は12通りをすべて扱い、倍率をかける因子や桁の異なる6種類の小数の組を混在させる。
- 問題バンクには十分な候補を用意するが、**全員に大量の同型問題を解かせる前提ではない**。固定位置で構造に気づかせた後、配置・組の種類を混合して認識と転移を確かめる。
- 発見型の学生用問題文に「小数を整数に直す」「まず2.5×4を探す」などの種明かしをしない。紙での出題セット・CBDでの診断はいずれも、前提技能と発見段階に応じて選ぶ。

全問題と分類・正答は [問題バンク一覧](../problems/A2_ALL_PROBLEMS.md) を参照。現在の試作PDFの42問には、この拡充分をまだ反映していない。

### 5.3 学習者に提示する出題セット（固定順の暫定案）

1. **A2-0：Fの基礎確認・補充**。**九九の単独問題は省き**、F1Bの20×5／2×50、F2Aの25×4、F3Aの125×8などへ。必要な箇所だけ補充し、既習者には短縮可能。D（分解）はこの系列の「次の段階」として一律に課さず、独立に導入する。
2. **A2-1：L1の発見**。習得済みのFの組をN3-P13に配置。順序変更の価値を実感する。
3. **A2-2：3数の位置の転移**。N3-P23を追加し、その後P12も含む混合。Fをむやみに同時上昇させない。
4. **A2-3：4数の位置の転移**。N4の6配置を扱い、数値・出題順も混ぜる。
5. **A2-4：方略選択**。必要に応じて**Dの分解あり／なし**、2組の有利な組、特別な組のない対照問題、既習パターンを混合する。
6. **A2-5：自己点検と統合**。初回答案、正答を見る前の見直し・修正、誤答検出、少数の転移確認。

これは**学習者全員に同一問題数を課す順序表ではない**。紙では目的別に複数の短いセットを編集し、CBT/CBDでは必要な下位技能だけ重点的に出題する。学習ブロックの問題数は試作時の学習者の負担を踏まえて定める。

### 5.4 出題順と混合の規則

- 初期はF・P・Dのうち**一度に主として変える軸を一つ**にし、つまずいた原因を推測しやすくする。
- 固定配置の導入以外は、位置コード・数値の種類が予測可能な周期にならないよう、出題数を制御して混ぜる。
- 類似数値の問題だけを繰り返し、答えを暗記して先へ進める状態を避ける。同じ式の再利用には意図を付ける。
- 工夫の必要がない対照問題は、工夫の価値を発見する導入を妨げない段階で入れる。
- CBT/CBDでは不得意な軸の出題に偏りすぎず、習得済みの軸も時々再確認して保持・転移を測る。

## 6. L1「発見型」の具体的な授業内フロー

1. 学生用には「計算してください」程度の指示だけを示す。題名で「順序を変えよう」と教えない。
2. まず各自で解き、必要なら途中式を残す。発見した問題に本人が小さく印を付けられるようにする（初回から印の意味を過度に指示しない）。
3. 途中で「もっと簡単な計算がある」と自発的に気づいたら、同じ見方が次の問題にも使えるか試す。
4. 様子を見て段階的な支援を入れる（例：①計算の順序は必ず左からか？ ②先に掛けると簡単になる2数がないか？ ③代表例の解法を比較）。**数問後の強制ヒントを固定しない**。
5. 発見後、非効率な方法との負担の違いを短く振り返る。その後は見た目や位置を変えた問題に進む。

「未発見」の状態を長く引き延ばすことは目的ではない。計算技能を既に身につけている学生が、初問から効率的に解く場合も正当に扱う。

## 7. G3：自己点検と記録

導入直後に「100になる組を探せ」と予測させると、解法を先取りする可能性がある。初期のL1では点検のヒントを抑え、**発見後のL4**で検算・数量感覚を明示的に扱う。

| 検証の観点 | A2での具体例 | 留意点 |
|---|---|---|
| 概算・桁（M1/M8） | 25×37×4 は数千程度 | 概算は正答の代用ではない |
| 末尾の0・倍数（M4/M7） | 25×4×37 は100の倍数 | 組を事前に示すと種明かしになる |
| 別の括り方（M6） | (25×4)×37 と 25×(4×37) の照合 | 毎回両方の筆算は不要 |
| 逆算（M5） | 結果を4等分して25×37と比べる | 逆算そのものが煩雑な場合は使わない |

**紙での最小記録案**：通常の計算欄に加え、選択した一部の問題だけ「初回の答え」「見直し後の答え」「途中で方法を変えた／誤りに気づいた」の印を入れる。正答を見る前の修正と、解答公開後の修正を区別する。確信度の記録は全問必須としない。

**他者の答案を判定する問題**では、誤りを含む式と正しい式を混ぜ、なぜ判定したかを短く説明させる。結果だけでなく、桁・末尾・計算構造からの違和感を促す。

### 7.1 将来のCBT/CBD：下位技能を診断する適応型ドリル

紙のPDFを当面の主教材とする一方、**CBT（Computer Based Testing）／CBD（Computer Based Drill）では、解答履歴をもとに個々の苦手部分を推定し、次の出題と支援を調整する**ことを将来要件とする。A2だけでもF・P・O・Mが異なるため、モジュール単位の「できる／できない」で判断しない。

| 観察した結果（例） | 疑う弱点 | 次に提示する診断・練習の候補 |
|---|---|---|
| 25×4単独が不正解 | F：数の組の計算 | 4×25、25×2→50×2など。必要ならF2へ戻る |
| 2数は正解、3数では有利な組を選べない | P：組の認識・位置探索 | 習得済みFのままP13固定→P23→P31等の逆向きも含めた混合 |
| 25×4は正解、25×12では使える4に気づかない | D：数の分解の発見 | F2Aを固定し、D0→D2の対比や分解練習 |
| 組は選べるが全体の答えが不正解 | O：方略の実行または別の算術 | 選択した組の積、残りの掛け算を分離して確認 |
| 特定の配置のみ誤る | 位置への依存 | 同じFを保ち、苦手な配置を重点的に提示 |
| 答えがおかしくても修正できない | M：自己点検 | 桁・末尾の0・別の括り方による検証練習 |

これは**仮説に基づく次の問題選択**であり、単問の正誤で弱点を確定しない。同じ技能の複数の問題や異なる数値・配置で再確認し、誤答の偶然性と学習者の複数の正しい解法を考慮する。

- 最終答案の正誤だけではF/P/Oを区別しにくい。必要に応じて「まず2数の積」「先に掛ける2数の選択」「計算結果」のように**観察対象を切り分ける短問**を使う。
- ただし発見型L1の冒頭から「先に掛ける2数を選べ」と表示すると種明かしになる。診断用の明示的な問いは、発見段階の後または必要な支援の段階で提示する。
- 将来の選択ロジック例：**短い診断→弱点の仮説→対応する数問→再診断→先へ進む／支援を変える**。正答・誤答の傾向、ヒント利用、初回回答から自己修正までを参照する。反応時間は補助情報に留める。
- 出題を適応化しても、既習の配置や数値を時々混ぜて**転移・保持を確認**する。得意な技能だけを出し続けたり、同じ問題の記憶だけで正答できるようにしない。
- この段階では診断規則・閾値・技術構成・個人ログ保存方式は**未決定**。個人情報は公開リポジトリに保存しない。

## 8. 作問・採用・公開の品質ゲート

### 8.1 各問題で確認すること

- 正答が厳密に正しいか、代表的な短い解法が成立するか。
- 想定する有利な組の位置が正しく記録されているか。異なる組にも予期しない「近道」がないか（あれば複数解法として記録）。
- **工夫しない場合と工夫した場合の落差**：筆算回数、中間数値の桁、暗算しやすさを比較したか。
- その問題で新しく必要になる知識がないか。初期は整数の積のみにする。**F（系列と倍率）・P（位置と向き）・D（分解操作）を別々に記録**し、複数を不用意に同時に難しくしない。
- 解法を知らなくても使える自己点検の手がかりがあるか。なくても「発見型」等の目的に照らして採否を決める。
- 問題の見出し、連番、並び順、例示によって先に方法が漏れていないか。
- 学生の効率的な別解や、左から計算した方が自然な場合も許容しているか。

### 8.2 ブロック・教材全体で確認すること

- 3数の3配置、4数の6配置が、固定→混合という学習順に沿ってカバーされているか。
- 出題数の偏りと、連続する問題の数値・解答の重複を確認したか。
- L1とL2を混同せず、発見の余地・適切な支援・定着練習の双方があるか。
- L4では正答提示前の自己点検が可能か。別解法を強制して過剰負担にしていないか。
- 学生用・解答解説用・教員用を分離し、印刷しやすい紙面と十分な計算欄を用意しているか。

## 9. 次工程（STEP 4）への受け渡し

1. **固定48問という前提を使わず**、F×P×D×N×O×M×Lの網羅・診断目的から必要な問題バンクの範囲を定める。A2-0の基礎問題とAB/BA両順序を追加し、各詳細パターンの数値違いを補充する。
2. 各問題に本書4.1の**一意なID**、正答、少なくとも1つの効率的解法、主な誤答、自己点検の観点を付ける。既存28候補は新命名規則（F1A/F2A/F3A、向きを含むP、D0）で管理し、分解ありの問題はD1/D2/DBで追加する。IDは教材内の掲載位置やL分類が変わっても維持する。
3. 学生用・解答解説用・教員用を分けた印刷原稿を試作する。
4. 全問題の正答と配置コードを検査し、PDFの数式・余白・印刷品質を確認する。
5. 可能なら学生による試用を通じて、想定した発見順や難易度を見直す。

現時点でPDF作成方法、YAML/JSON等のデータ形式、評価欄の最終レイアウトは固定しない。設計を優先し、試作結果に合わせて選択する。
