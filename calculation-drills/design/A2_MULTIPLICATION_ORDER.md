# A2詳細設計 — 掛け算の順序を工夫する

状態：**詳細設計 v0.3／教材未完成**。対象は算術の積の交換法則・結合法則。**固定48問案は廃止し、下位技能を網羅する問題バンクから、紙のプリントや将来のCBD用出題を組み立てる。** 以下は学習上の役割・分類・採否基準を定めるもので、完成した学生用教材ではない。

上位方針：[CONCEPT](CONCEPT.md)／[DESIGN](DESIGN.md)／[ASSESSMENT](ASSESSMENT.md)／[SKILLS](SKILLS.md)

## 1. 学習目標と到達行動

- **G1：発見・探索**。数の並びを眺め、自然な左から順の計算に固執せず、先に掛けるとよい2数を見つける。
- **G2：計算最適化**。交換法則・結合法則を使い、25×4=100、125×8=1000、20×5=100 などを利用して計算量を減らす。
- **G3：自己監視・修正**。計算前後の桁・概算・末尾の0の個数・別の括り方などで、解答を見る前に疑問を持ち、必要なら修正する。
- **転移目標**。有利な2数がどの位置にあっても、また「特別な有利な組がない」ときも、計算方法を選び直せる。

**重要な区別**：(1,2) に有利な組がある問題は、左から計算すればすでに効率的な場合がある。「位置網羅」に必要だが、必ずしも「順序変更の発見」を促す問題ではない。複合問題・対照問題として位置づけ、発見型の中心にはしない。

### 1.1 有利な2数の積自体にも前提技能がある

例えば `25×37×4` で25と4を選択できても、`25×4=100` をすぐに計算できなければ工夫の効果を実感しにくい。**数の組の計算**、**有利な組の認識**、**実際の順序変更**を別の到達目標・診断対象にする。

### F1〜F5：有利な数の組そのものの難度

| Fコード | 数の組（逆順も扱う） | ねらい |
|---|---|---|
| F1 | 2×5、5×2 | 10を作る基本 |
| F2A / F2B | 20×5、2×50（および各逆順） | 10の倍数から100を作る |
| F3 | 25×4、4×25 | 100を作る別の組。必要なら25×2→50×2を経由 |
| F4 | 125×8、8×125 | 1000を作る組。必要なら125→250→500→1000を経由 |
| F5A / F5B / F5C（発展） | 2.5×4、0.25×4、0.125×8（および各逆順） | 小数での数の表現。C系列との重なりを明示 |

F1〜F4の進行は**初期仮説**であり、学生の習熟状況に応じて省略・再練習する。F5は小数の別技能を含み得るため発展扱いとする。

### F6：数を分解する操作（F1〜F5とは独立）

**F6は「F1→F2→…→F6」という第6段階ではない。** F1〜F5でどの有利な組を使うかと、**その一部（または両方）を分解して取り出す必要があるか**は別の軸である。

| 元の式 | 基本となる組 | F6（分解） | 代表的な考え方 |
|---|---|---|---|
| 25×4 | F3 | なし | 25×4=100 |
| 25×12 | F3 | あり | 12=4×3 として25×4を作る |
| 125×8 | F4 | なし | 125×8=1000 |
| 125×24 | F4 | あり | 24=8×3 として125×8を作る |
| 2×15 | F1 | あり | 15=5×3 として2×5を作る |
| 2.5×12 | F5A | あり | 12=4×3 として2.5×4を作る |

**診断上の区別**：`25×4`はできても`25×12`で4を取り出せない学生には、F3の再反復ではなくF6の練習が必要な場合がある。逆にF6で分解できても、F3の積が不確実な学生もいる。F6あり／なしを同じ基礎組・配置で対比できるようにする。分解を要する問題をF6単独の「数の組」として扱わない。

IDではF6の有無と分解対象を **`DEC0`（分解なし）／`DECA`（組のAを取り出す）／`DECB`（組のBを取り出す）／`DECAB`（両方を取り出す）** として記録する。`DECA`等はF6ありの下位型であり、F1〜F5とは直交する。詳細は4.1節を参照。

A2では少なくとも次を区別する。

1. **F（数の組の計算）**：`25×4` 単独を計算できるか。
2. **P（組の発見）**：`25×37×4` から25と4を見いだせるか。
3. **O（方略の選択・実行）**：見つけた2数を先に掛け、全体を正しく計算できるか。

これらに**M（検算・違和感検出）**が重なる。正しい最終答えだけから、どの能力を使えたか断定しない。

**紙の教材への含意**：先行する短い2数の練習・確認（A2-0）を設ける余地を残す。発見型の本編は、数の組を十分に扱える段階で実施するか、必要に応じて支援する。FとPを同時に難しくすると、つまずきの原因を特定できなくなる。

## 2. 問題設計の軸と制約

| 軸 | 本モジュールでの変化 |
|---|---|
| P：配置 | 3数の P12/P13/P23、4数の P12/P13/P14/P23/P24/P34（以下、1始まりの位置） |
| N：因子数 | 3数→4数→2組の有利な組、必要なら5数以上 |
| V：数値 | 因子全体の大きさや種類。まず整数のみ、小数は発展に回す |
| F：有利な組自体の難度 | F1〜F5の数の組の種類・計算習熟度。逆順も扱う |
| DEC：数の分解操作 | F6なし（DEC0）、あり（DECA/DECB/DECAB）。F1〜F5と独立に組み合わせる |
| K：技能 | 導入は A2 単独。小数の分数化（C1）・約分（A1）等は後の複合問題で扱う |
| D：探索難度 | 位置固定→混在→複数の有利な組→見かけ上有利な組がない対照問題 |

初期の問題は**「有利な組」を1組だけ明瞭に配置**し、他の組合せに同程度に目立つ近道がないか確認する。ただし数学的に唯一の最適経路を強制しない。計算しやすさは学習者に依存するため「代表的な短い解法」と記録する。

初期は整数・正数で統一し、負号、小数、分数、指数、根号、乗除混合は新たな技能を要求し得るので分離する。工夫しない方法が簡単すぎる問題は発見型に置かず、対照・選択問題で活用する。

## 4. 問題IDの命名方針と初期素材

### 4.1 問題IDの構造

原則：**A2-N{因子数}-P{組の位置}-F{数の組}-AB/BA-DEC{分解状態}-{2桁連番}**。

例：`A2-N3-P13-F3-AB-DEC0-01` は「A2、3因子、位置1と3、F3の25×4、AB順、分解なし、この詳細パターンの数値例01」を表す。`A2-N2-P12-F3-AB-DECB-01` は「25×12（12から4を取り出す）」の例であり、F3とF6が同時に使われる。

| 部分 | 意味・規則 |
|---|---|
| `A2` | 主要技能 |
| `N2`／`N3`／`N4` | **分解する前の式に書かれた因子数**。25×12はN2 |
| `P12`／`P13` 等 | 有利な組に関わる**元の因子（または分解対象の因子）の位置**。左から1始まり |
| `F1`〜`F5C` | 分解操作とは独立した、基本となる2数の組の種類 |
| `AB`／`BA` | 基準となる組のA側の因子／B側の因子（分解対象を含む）が、**元の式でどちらから並ぶか** |
| `DEC0`／`DECA`／`DECB`／`DECAB` | F6の適用状態。0はなし、A/Bは各側の因子から必要な数を取り出す、ABは両側から取り出す |
| `01`〜`99` | **最後のハイフンと2桁**は、上の詳細パターンが同じで数値のみ異なる問題の連番 |

F1〜F5の基準となる数の組は以下のように固定する。F6はこの表の**行ではなく独立した操作軸**である。

| Fコード | 基準順（AB） | 逆順（BA） | 備考 |
|---|---|---|---|
| F1 | 2×5 | 5×2 | 10を作る |
| F2A | 20×5 | 5×20 | 100を作る |
| F2B | 2×50 | 50×2 | 100を作る |
| F3 | 25×4 | 4×25 | 100を作る |
| F4 | 125×8 | 8×125 | 1000を作る |
| F5A / F5B / F5C | 2.5×4 / 0.25×4 / 0.125×8 | それぞれ逆順 | 小数を含む発展 |

**コード別の実例**：

| 仮ID | 元の数式 | 構造 |
|---|---|---|
| `A2-N2-P12-F3-AB-DEC0-01` | 25×4 | F3、分解なし |
| `A2-N2-P12-F3-AB-DECB-01` | 25×12 | F3、B側の12から4を取り出す（12=4×3） |
| `A2-N2-P12-F3-BA-DECB-01` | 12×25 | F3、B側の12から4を取り出す、逆順 |
| `A2-N2-P12-F4-AB-DECB-01` | 125×24 | F4、B側の24から8を取り出す（24=8×3） |
| `A2-N2-P12-F1-AB-DECA-01` | 6×5 | F1、A側の6から2を取り出す（6=2×3） |
| `A2-N2-P12-F1-AB-DECAB-01` | 6×15 | F1、両側から2と5を取り出す（6=2×3、15=5×3） |
| `A2-N2-P12-F5A-AB-DECB-01` | 2.5×12 | F5A、B側の12から4を取り出す |

`DEC`コードはF6の**有無だけでなく、どちらの因子を分解するか**も区別する。具体的な分解式（例：12=4×3、28=4×7）と別解法はメタデータに記録する。たとえば`25×12`と`25×28`は、どちらも`A2-N2-P12-F3-AB-DECB`を共有し、末尾の`-01`、`-02`で区別できる。

複数の有利な組がある場合は、**位置の早い組から**、P・F・AB/BA・DECをそれぞれアンダースコア区切りで並べ、同じ順序で対応させる。例：`A2-N4-P13_P24-F3_F4-AB_BA-DEC0_DEC0-01`（25×8×4×125）。特別な組を設定しない対照問題では`A2-N3-PNONE-FNONE-NA-DEC0-01`などとする。

- 位置・基本のF・向き・分解の有無／対象・因子数・有利な組の数が変われば、末尾の数字だけで区別せず**対応するコードを変える**。F6を使う場合でもFの欄にはF1〜F5を記し、`F6A`や`F6B`を単独の組コードとして使用しない。
- L1〜L5（学習形式）、M（自己点検法）、難易度、誤答パターン、提示順は**可変のメタデータ**とし、問題IDに含めない。同じ問題はPDFとCBDのどちらで使っても同じID。
- 既存の候補28問はすべて分解なしなので、旧ID `…-AB-01` を `…-AB-DEC0-01` のように**DEC0を挿入して移行**する。現時点では仮IDであり、公開済み問題・学習者記録は存在しない。旧IDとの対応が追えるよう変更規則を明記する。
- 登録時にはID重複・式重複・P/F/AB/DECと式の整合を確認する。別解が複数ある場合は**代表的な狙いをIDに採用し、他の使える組・分解法はメタデータへ**記す。
- 長大な複合IDや同一詳細パターンで99問を超える場合は、独断で命名規則を変更せず相談する。

### 4.3 問題を確定する際のF×P×DECの分離

初稿の候補にはF3・F4に相当する問題が多いが、**導入から25×4や125×8を暗算できることを前提としない**。単独の2数の計算確認（F）を設けた上で、位置固定（P13等）と混合（P12/P13/P23）に進める。

**F6の有無（DEC）も独立に変える**。例えば、F3・位置P12を固定して`25×4`（DEC0）と`25×12`（DECB）を比較すれば、組の積を計算する技能と、数の分解に気づく技能を分けて確認しやすい。F、配置P、分解DECを一度に難しくしない。

## 5. 問題バンクを中心とする設計・配列

### 5.1 固定48問案の撤回

当初の48問案は、主に3数・4数の**位置の網羅**から逆算した試算であり、F1〜F5の数の組の習得、F6（数の分解）の有無、逆順、数の組の認識、実行、自己点検、対照問題を扱うには不十分だった。**48問でA2を完成させるという前提は廃止**する。

今後は問題バンクに十分な候補を蓄積し、目的に応じて紙のプリントでは一部を選び、将来のCBT/CBDでは個別の習熟状況に応じて出題する。**問題バンクの収録数と、一人の学習者が解く問題数は別**である。最初から総数の上限を定めない。100〜150問程度という数字は以前の粗い見積もりにすぎず、達成ノルマではない。

### 5.2 問題バンクの網羅軸

| 軸 | 管理・点検する内容 |
|---|---|
| F：2数の組の習熟 | F1、F2A・F2B、F3、F4とそれぞれのAB/BA。F5は小数の発展 |
| DEC（F6）：数の分解 | F1〜F5それぞれに対して、DEC0（なし）、DECA/DECB/DECAB（あり）を必要に応じて設定 |
| P：位置 | 3数のP12/P13/P23、4数のP12/P13/P14/P23/P24/P34 |
| N：因子数 | N2の基礎、N3の発見、N4の混合。N5以上は必要に応じて |
| O：方略実行 | 2数を先に計算して全体を解く／別解の比較／順序変更が不要な場合の判断 |
| M：自己点検 | 概算、桁、末尾の0、逆算、異なる方法による照合、正誤判定 |
| L：学習形式 | 発見（L1）、習得（L2）、転移（L3）、自己点検（L4）、総合（L5） |

**F6はF1〜F5と直交する技能であり、数の組の第6段階ではない。全軸の直積を機械的に埋める必要はない**。F1の段階でもF6あり／なしを比較できるし、F4以降までF6を待つ必要はない。ただし分解練習の導入時機は学生の前提知識に合わせる。診断・習熟確認に必要な差を作れるセルを優先して、同じ詳細パターンに複数の数値違い（`-01`, `-02` …）を蓄積する。IDのFとPは索引として使い、習熟度、誤答特徴、出題履歴などは別メタデータで管理する。

### 5.3 学習者に提示する出題セット（固定順の暫定案）

1. **A2-0：Fの基礎確認・補充**。2×5と逆順、20×5／2×50と逆順、25×4と逆順、125×8と逆順へ。必要な箇所だけ補充し、既習者には短縮可能。F6の分解はこの系列の「次の段階」として一律に課さず、別の課題として導入する。
2. **A2-1：L1の発見**。習得済みのFの組をN3-P13に配置。順序変更の価値を実感する。
3. **A2-2：3数の位置の転移**。N3-P23を追加し、その後P12も含む混合。Fをむやみに同時上昇させない。
4. **A2-3：4数の位置の転移**。N4の6配置を扱い、数値・出題順も混ぜる。
5. **A2-4：方略選択**。必要に応じて**F6の分解あり／なし**、2組の有利な組、特別な組のない対照問題、既習パターンを混合する。
6. **A2-5：自己点検と統合**。初回答案、正答を見る前の見直し・修正、誤答検出、少数の転移確認。

これは**学習者全員に同一問題数を課す順序表ではない**。紙では目的別に複数の短いセットを編集し、CBT/CBDでは必要な下位技能だけ重点的に出題する。学習ブロックの問題数は試作時の学習者の負担を踏まえて定める。

### 5.4 出題順と混合の規則

- 初期はF・P・DEC（F6）のうち**一度に主として変える軸を一つ**にし、つまずいた原因を推測しやすくする。
- 固定配置の導入以外は、位置コード・数値の種類が予測可能な周期にならないよう、出題数を制御して混ぜる。
- 類似数値の問題だけを繰り返し、答えを暗記して先へ進める状態を避ける。同じ式の再利用には意図を付ける。
- 工夫の必要がない対照問題は、工夫の価値を発見する導入を妨げない段階で入れる。
- CBT/CBDでは不得意な軸の出題に偏りすぎず、習得済みの軸も時々再確認して保持・転移を測る。

## 6. L1「発見型」の具体的な授業内フロー

1. 学生用には「計算してください」程度の指示だけを示す。題名で「順序を変えよう」と教えない。
2. まず各自で解き、必要なら途中式を残す。発見した問題に本人が小さく印を付けられるようにする（初回から印の意味を過度に指示しない）。
3. 途中で「もっと簡単な計算がある」と自発的に気づいたら、同じ見方が次の問題にも使えるか試す。
4. 様子を見て段階的な支援を入れる（例：①計算の順序は必ず左からか？ ②先に掛けると簡単になる2数がないか？ ③代表例の解法を比較）。**数問後の強制ヒントを固定しない**。
5. 発見後、非効率な方法との負担の違いを短く振り返る。その後は見た目や位置を変えた問題に進む。

「未発見」の状態を長く引き延ばすことは目的ではない。計算技能を既に身につけている学生が、初問から効率的に解く場合も正当に扱う。

## 7. G3：自己点検と記録

導入直後に「100になる組を探せ」と予測させると、解法を先取りする可能性がある。初期のL1では点検のヒントを抑え、**発見後のL4**で検算・数量感覚を明示的に扱う。

| 検証の観点 | A2での具体例 | 留意点 |
|---|---|---|
| 概算・桁（M1/M8） | 25×37×4 は数千程度 | 概算は正答の代用ではない |
| 末尾の0・倍数（M4/M7） | 25×4×37 は100の倍数 | 組を事前に示すと種明かしになる |
| 別の括り方（M6） | (25×4)×37 と 25×(4×37) の照合 | 毎回両方の筆算は不要 |
| 逆算（M5） | 結果を4等分して25×37と比べる | 逆算そのものが煩雑な場合は使わない |

**紙での最小記録案**：通常の計算欄に加え、選択した一部の問題だけ「初回の答え」「見直し後の答え」「途中で方法を変えた／誤りに気づいた」の印を入れる。正答を見る前の修正と、解答公開後の修正を区別する。確信度の記録は全問必須としない。

**他者の答案を判定する問題**では、誤りを含む式と正しい式を混ぜ、なぜ判定したかを短く説明させる。結果だけでなく、桁・末尾・計算構造からの違和感を促す。

### 7.1 将来のCBT/CBD：下位技能を診断する適応型ドリル

紙のPDFを当面の主教材とする一方、**CBT（Computer Based Testing）／CBD（Computer Based Drill）では、解答履歴をもとに個々の苦手部分を推定し、次の出題と支援を調整する**ことを将来要件とする。A2だけでもF・P・O・Mが異なるため、モジュール単位の「できる／できない」で判断しない。

| 観察した結果（例） | 疑う弱点 | 次に提示する診断・練習の候補 |
|---|---|---|
| 25×4単独が不正解 | F：数の組の計算 | 4×25、25×2→50×2など。必要ならF2へ戻る |
| 2数は正解、3数では有利な組を選べない | P：組の認識・位置探索 | 習得済みFのままP13固定→P23→混合 |
| 25×4は正解、25×12では使える4に気づかない | F6（DEC）：数の分解の発見 | F3を固定し、DEC0→DECBの対比や分解練習 |
| 組は選べるが全体の答えが不正解 | O：方略の実行または別の算術 | 選択した組の積、残りの掛け算を分離して確認 |
| 特定の配置のみ誤る | 位置への依存 | 同じFを保ち、苦手な配置を重点的に提示 |
| 答えがおかしくても修正できない | M：自己点検 | 桁・末尾の0・別の括り方による検証練習 |

これは**仮説に基づく次の問題選択**であり、単問の正誤で弱点を確定しない。同じ技能の複数の問題や異なる数値・配置で再確認し、誤答の偶然性と学習者の複数の正しい解法を考慮する。

- 最終答案の正誤だけではF/P/Oを区別しにくい。必要に応じて「まず2数の積」「先に掛ける2数の選択」「計算結果」のように**観察対象を切り分ける短問**を使う。
- ただし発見型L1の冒頭から「先に掛ける2数を選べ」と表示すると種明かしになる。診断用の明示的な問いは、発見段階の後または必要な支援の段階で提示する。
- 将来の選択ロジック例：**短い診断→弱点の仮説→対応する数問→再診断→先へ進む／支援を変える**。正答・誤答の傾向、ヒント利用、初回回答から自己修正までを参照する。反応時間は補助情報に留める。
- 出題を適応化しても、既習の配置や数値を時々混ぜて**転移・保持を確認**する。得意な技能だけを出し続けたり、同じ問題の記憶だけで正答できるようにしない。
- この段階では診断規則・閾値・技術構成・個人ログ保存方式は**未決定**。個人情報は公開リポジトリに保存しない。

## 8. 作問・採用・公開の品質ゲート

### 8.1 各問題で確認すること

- 正答が厳密に正しいか、代表的な短い解法が成立するか。
- 想定する有利な組の位置が正しく記録されているか。異なる組にも予期しない「近道」がないか（あれば複数解法として記録）。
- **工夫しない場合と工夫した場合の落差**：筆算回数、中間数値の桁、暗算しやすさを比較したか。
- その問題で新しく必要になる知識がないか。初期は整数の積のみにする。**F（2数の組）・P（配置）・DEC（F6の分解操作）を別々に記録**し、複数を不用意に同時に難しくしない。
- 解法を知らなくても使える自己点検の手がかりがあるか。なくても「発見型」等の目的に照らして採否を決める。
- 問題の見出し、連番、並び順、例示によって先に方法が漏れていないか。
- 学生の効率的な別解や、左から計算した方が自然な場合も許容しているか。

### 8.2 ブロック・教材全体で確認すること

- 3数の3配置、4数の6配置が、固定→混合という学習順に沿ってカバーされているか。
- 出題数の偏りと、連続する問題の数値・解答の重複を確認したか。
- L1とL2を混同せず、発見の余地・適切な支援・定着練習の双方があるか。
- L4では正答提示前の自己点検が可能か。別解法を強制して過剰負担にしていないか。
- 学生用・解答解説用・教員用を分離し、印刷しやすい紙面と十分な計算欄を用意しているか。

## 9. 次工程（STEP 4）への受け渡し

1. **固定48問という前提を使わず**、F×P×DEC（F6）×N×O×M×Lの網羅・診断目的から必要な問題バンクの範囲を定める。A2-0の基礎問題とAB/BA両順序を追加し、各詳細パターンの数値違いを補充する。
2. 各問題に本書4.1の**一意なID**、正答、少なくとも1つの効率的解法、主な誤答、自己点検の観点を付ける。既存28候補は`DEC0`追加後のIDで管理し、F6ありの問題は新たなDECコードで追加する。IDは教材内の掲載位置やL分類が変わっても維持する。
3. 学生用・解答解説用・教員用を分けた印刷原稿を試作する。
4. 全問題の正答と配置コードを検査し、PDFの数式・余白・印刷品質を確認する。
5. 可能なら学生による試用を通じて、想定した発見順や難易度を見直す。

現時点でPDF作成方法、YAML/JSON等のデータ形式、評価欄の最終レイアウトは固定しない。設計を優先し、試作結果に合わせて選択する。
