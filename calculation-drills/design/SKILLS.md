# SKILLS — 計算技能の暫定分類

状態：暫定 v0.1。**4系列・22要素**（従来21要素にR8候補を追加）。技能IDは問題の整理と改訂追跡のために使う。領域間の重複は必要に応じて残し、教材化の途中で見直す。

## A：計算順序・演算の整理（5）

| ID | 技能 | 単一要素の例 |
|---|---|---|
| A1 | 積・商では約分を先にする | (36×7)/9 |
| A2 | 掛け算の順序・結合を変える | 25×37×4 |
| A3 | 足し算・引き算の順序を工夫する | 7.8+6.5+2.2 |
| A4 | 分配法則を逆向きに使って積をまとめる | 37×48+37×52 |
| A5 | 相殺する項を見つける | 8.3+4.7−8.3 |

## B：代数的な式の変形（4）

| ID | 技能 | 単一要素の例 |
|---|---|---|
| B1 | 同類項をまとめる | 7a−3a+2a |
| B2 | 共通因子をくくる | 3x+3y |
| B3 | 恒等式・因数分解を活用する | 51²−49² |
| B4 | 文字式を先に整理し、数値代入を遅らせる | (mv²)/m（m≠0） |

A4とB2は数学的な操作が重なるが、前者は数値計算の軽減、後者は一般式の変形という学習文脈を区別している。

**A2の下位技能と新命名規則**：基本の数の組と10のべき乗倍率（F1～F3 × A/B/C）、有利な組の位置と向き（P）、独立した分解操作（D0/D1/D2/DB）、計算方略の選択・実行（O）、自己点検（M）を区別する。

基本系列は **F1=2×5、F2=25×4、F3=125×8**。Aは基本形、Bは10倍・100倍など、Cは1/10倍・1/100倍などを表す。例えば20×5と2×50はどちらもF1Bとし、倍率変更だけでは分解扱いにしない。旧F6にあたる数の分解はDという独立軸に移す（25×4はF2A/D0、25×12はF2A/D2）。

問題ID例：`A2-F2A-N3P13-D0-01`。末尾2桁は同一詳細パターンの数値違いを表す。**このように下位要素を分類したIDを付ける思想は、今後のA1・A4・B・C・R系列にも適用する**が、それぞれの技能に適した分類軸と短いコードを個別に定義する。詳細は [DESIGN](DESIGN.md) と [A2詳細設計](A2_MULTIPLICATION_ORDER.md)。全22技能の分類自体は変更しない。

数学的な条件に注意すること：sqrt(a)sqrt(b)=sqrt(ab) は a,b≥0、sqrt(a)/sqrt(b)=sqrt(a/b) は a≥0,b>0、sqrt(a²)=|a|。平方根の和は一般に根号内で足せない。

新しい要素は、既存要素との相違・評価可能性・代表問題を確認してから追加する。
