# ASSESSMENT — メタ認知と評価

状態：暫定 v0.1。正答を見る前に「あれ？」と感じて検証・自己修正できる能力を、計算技能と並ぶ学習目標とする。

## 1. 自己点検の手がかり（M）

| ID | 方法 | 例 |
|---|---|---|
| M1 | 概算 | 49×21は約1000 |
| M2 | 範囲 | 8<√75<9 |
| M3 | 符号 | 主平方根は非負 |
| M4 | 桁・位取り | 0.02×0.3は0.01未満 |
| M5 | 逆演算 | 商×除数で被除数に戻る |
| M6 | 独立した別経路 | 約分と直接計算、式変形前後の比較 |
| M7 | 数学的構造・性質 | 整数性、平方の関係、同値性 |
| M8 | 既知の基準値との比較 | 25×39×4は3900 |

M1〜M8は排他的ではない。計算技能A/B/C/Rと組み合わせて用いる。**同じ計算をなぞり直すだけでは同じ誤りを繰り返す可能性がある**ため、できれば独立性の高い点検方法を採用する。

## 2. 自己点検を促す流れ

`事前予測 → 初回計算 → 確信度・違和感の確認 → 別手段による点検 → 必要なら修正 → 正答確認`

ただし全問で長い記録を強制しない。初期は点検方法を指定し、次に選ばせ、最後は指示がなくても必要な時に行う状態を目指す。発見型では、予測やヒントが工夫を先に明かさないよう提示時機を調整する。

## 3. 平方根特有の困難と対策

根号を含む最終答案（特に有理化や差）は大きさが直感的に見えにくいため、誤答への違和感が起きにくい。

参考概数（有効数字3桁）：**√2≈1.41、√3≈1.73、√5≈2.24、√7≈2.65**。

例：`1/(√3+√2) = √3−√2` は、左辺が約 `1/3.14≈0.32`、右辺が約 `1.73−1.41≈0.32`。さらに正値か、0と1の間か、元の式に戻るかを確認できる。

点検の方法を複数準備する：
- 整数の平方による上界・下界（例：2<√7<3）
- 根号式を3桁程度の概数で見積もる
- 二乗・逆数・有理化前の式による検証
- 正負・単調性・必要な定義域の確認

**注意**：近い平方根の差では、概数の丸め誤差が差に対して大きくなる。概数による大小の判断と、式の厳密な同値検証を区別する。概数表は学習目標に応じて問題の前／自己点検時に提示を使い分ける。

## 4. 誤答点検問題

誤った途中式だけでなく、**正しい途中式も混ぜる**。「誤り探し」だと決めつけて形式的に判定しないようにする。例：`√18+√8=√26` は誤り、`√50/√2=5` は正しい。

## 5. 観察・評価する指標（候補）

| 指標 | 記録方法・意味 |
|---|---|
| 初回正答率 | 答えを見る前の最初の答え |
| 工夫の利用率 | どの効率的手順を使ったか |
| 自力発見 | 何問目で方法を変えたか／どのヒントで気づいたか |
| 自己修正 | 初回誤答を正答確認前に修正したか |
| 確信度の妥当性 | 「自信がある」と実際の正誤の対応 |
| 転移 | 配置や技能が混合しても使えるか |
| 逆修正 | 初回正解を自己点検で誤答に変えなかったか |

自己修正率の候補定義：`（答えを見る前に正答へ修正した問題数）/（初回に誤答した問題数）`。分母0の場合は算出しない。

プリントでは正答率だけでなく、必要最小限の「方法を途中で変えた」「自力で修正した」印・欄を検討する。CBTでは初回入力・変更・ヒント利用・確信度を計測できる一方、**最終答案の入力だけでは計算過程を直接測れない**点に注意する。

## 6. 工夫を使わない理由の観察

計算の工夫を使わない場合に、**構造に気づかなかったのか**、**必要な式変形を知らなかったのか**、**知っていたが使わなかったのか**を区別する。最終答案や所要時間だけから断定せず、途中式・解法選択の説明・ヒント後の変化などで推測する。必要に応じて異なる支援（気づきのヒント、技能の説明、計算負担の比較）を用意する。

## 7. CBT/CBDにおける下位技能の診断と適応（将来構想）

計算ドリルをコンピュータ化する場合、**正答率だけで難易度を上下させるのではなく、つまずいた下位技能の仮説を立て、次の問題を適応的に選ぶ**ことを目指す。

問題バンクでは**総数を先に固定せず**、各下位技能について複数の数値違い・位置違いの問題を登録して再診断できるようにする。問題IDは式・構造の安定した識別子として使い、学習者がどの問題に回答したか、どのような支援を受けたかなどは別の履歴情報として扱う。

A2の例では、少なくとも次の要素を区別する。

| 下位要素 | 直接的な確認例 | 一致しない結果から考えること |
|---|---|---|
| F（系列・倍率）：有利な2数の積 | F1Aの2×5、F1Bの20×5／2×50、F2Aの25×4、F3Aの125×8（逆順も） | 基本系列や10のべき乗倍率への習熟が異なるかもしれない |
| D（旧F6）：分解する力 | 25×4（D0）はできるが25×12（D2）で4を見いだせるか | 基本の積は既習でも、分解して組を作る力が不足しているかもしれない |
| P：有利な組の認識 | 3数・4数から組を選択できるか | 特定位置の組にしか気づかないかもしれない |
| O：計算順序の選択・実行 | 選んだ組を先に掛けて正答できるか | 位置の発見と算術的な実行を分ける必要 |
| M：誤答への違和感・修正 | 初回答案・再点検・修正・確信度 | 計算はできても自己監視が弱い可能性 |

**推定であって確定診断ではない。** Fの基本系列・倍率、Pの位置・向き、Dの分解の有無・対象を別々に記録し、`25×4`（F2A・D0）と`25×12`（F2A・D2）のように基本の組を固定して比較する。1問の誤りから原因を決めず、同じ下位技能に関する複数問題、異なる配置、段階的なヒント後の挙動で確認する。最終答案のみではF・P・Oを分離できないため、解法選択や2数の計算などの短い診断問題を適宜用意する。ただし発見型の最初から解法を先取りする設問を挿入しない。

**適応型の基本ループ（案）**：短い現状把握 → 苦手候補の推定 → その要素を主に練習する出題・ヒント → 複数問で再確認 → 次の段階へ進む／別の支援へ切り替える。得意な領域も時折再出題し、定着と転移を確認する。

記録候補：問題IDとタグ、初回解答と最終解答、正答前の自己修正、ヒント使用、選択した組や計算経路（取得できる場合）、確信度（選択的）、所要時間（補助的）。**反応時間が長いことだけで能力不足と判断しない。**

これらは教育上の将来要件であり、現時点では個人ログの収集やログイン機能は実装しない。保存方法、本人への説明、未成年を含む利用者のプライバシー、データ保持とアクセス権はCBT/CBD設計時に別途検討する。公開GitHubに個人データを保存しない。

## 8. 測定上の注意

教材のねらい（発見、効率化、自己点検）と、測定できる行動を区別する。ヒントによる修正と無ヒントの自己修正を同一視しない。所要時間の短さだけを成果としない。学生個人の学習ログは公開リポジトリに保存しない。
