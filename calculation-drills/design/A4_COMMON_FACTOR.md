# A4 詳細設計 — 共通因子を見つけて掛け算を減らす

状態：**詳細設計 v0.1／問題バンク220問・試作PDF72問を作成済み、授業試用は未実施**（2026-11-22）。関連文書：[CONCEPT](CONCEPT.md)／[DESIGN](DESIGN.md)／[SKILLS](SKILLS.md)／[ASSESSMENT](ASSESSMENT.md)。

## 1. 教育目標

A4は、数値計算において **分配法則を逆向きに使い、掛け算の回数を減らす**ことを自発的に発見・実行する技能である。B2（文字式の因数分解）とは扱う学習文脈を区別する。

例えば `4387×2764+4387×3129` は、別々なら4桁×4桁の乗算が2回だが、`4387×(2764+3129)=4387×5893` なら乗算は1回で済む。**くくった後の和が10・100などにならなくても利益がある**。くくった後の積まで簡単になる場合は「さらにうれしい」ボーナスと考え、初期の問題群をそればかりにしない。

学習者が苦手になり得る点を区別する：
- 共通因子に**気づく**（視覚探索、項の位置・長さに依存しない）。
- 共通因子を使って**式をまとめる**（分配法則の逆向き）。
- 残る数を**加減算**し、最後に積を求める。
- 手順を**自発的に選択**し、計算が楽になったことを実感する。
- **見直し**によって誤りや異常な桁を検出する。

## 2. 独立に設計する軸

| 軸 | コード・意味 | 例・留意点 |
|---|---|---|
| N | `N2`, `N3`, `N4`：**元の項数** | 当面はN2/N3を優先 |
| T | `T12`, `T13`, `T23`, `T123`：**共通因子を持つ項の位置** | 3項の導入はT12/T13/T23（**2項だけ**）、その後T123（**3項とも**） |
| P | `P11`, `P22`, `P12`, `P21`：**対象項の積の中で共通因子が何番目か** | N3T123なら`P121`等、Tに書いた項順に対応 |
| L | `L33`, `L44`：**共通因子の桁数と、残りの各因子の桁数** | 3桁×3桁、4桁×4桁を中心に、L22/L32/L43/L52も比較用 |
| R | くくった後の和・差の性質：`R0` 普通の数、`R1` 10の倍数（10の冪を除く）、`R2` 10の冪 | R0を**中心**とし、R1/R2はボーナス |
| K | `K0` A4中心／`K1` A4の後にA2的な数の組をさらに活用 | `20×50=1000`, `25×40=1000`, `125×80=10000`。R1×K1 |
| H | `H0` 共通因子が元の各項に**そのまま見える**／`H1` 一部の数の分解が必要 | **初稿はH0のみ**。H1は後の複合学習 |
| S | `S0` 加算のみ／`S1` 加減算を含む | **初稿はS0のみ**。差の問題は後で検討 |

**Lの定義**：`Lab` の a は共通因子の十進桁数、b は**対象項で共通因子を除いた各因子**の十進桁数で、初稿ではすべて揃える。対象外の項の数もなるべく同じ桁数にそろえ、見た目の差を手がかりにしすぎないようにする。桁数は計算負担の代替指標であり、数の性質（末尾0等）も別メタデータで見る。

**Rの定義**：和を `s` とし、R2は `s=10^k`（k≥1）、R1は `s` が10の倍数かつ10の冪ではない場合、R0はそれ以外。R0だから計算負担の削減が弱いとは限らない。

**K1はR1とは独立の「2段目の工夫」**：R1の和50・40・80などと共通因子20・25・125を組み合わせ、くくった後の積も暗算しやすくする。どの問題もA2を必須の別技能にするかは、授業段階で判断する。

**発見負荷と計算負荷は別**：位置P、項数N/T、桁数の均一さは「共通因子に気づけるか」に影響する可能性がある。一方、桁数Lや元の乗算回数は「くくる価値」に影響する。実際の発見難度はIDから断定せず`discovery_difficulty`等で後から観察・記録する。

## 3. 分類を表す問題ID（仮）

**基本形式：`A4-N2T12-P11-L33-R0K0-H0S0-01`**

| セグメント | 説明 |
|---|---|
| `A4` | 主要技能 |
| `N2T12` | 元の項数と、まとめる対象の項番号 |
| `P11` | Tの順に並べた対象項での共通因子の前／後位置 |
| `L33` | 共通因子3桁、残り因子は3桁 |
| `R0K0` | くくった後の和の性質、A2等との複合 |
| `H0S0` | 直接見える共通因子、加算のみ |
| `01` | **同じ詳細構造内の数値違い**。最後のハイフン＋2桁のみ |

例：`A4-N3T13-P12-L33-R0K0-H0S0-01` は「3項の1・3項にだけ共通因子、1項目では前、3項目では後、3桁×3桁、通常の和、A4中心」を意味する。

**IDの思想**：項の位置や桁の構造などをできるだけ短いコードで明示し、難易度の主観的評価・想定誤答・指導順・初回答案・学習者ごとの履歴などは**IDと別のメタデータ**へ。N2ではT12が固定だが、N3以上と同じ規則で検証できるよう保持する。分類の重複や冗長性が顕在化したら公開前に再検討する。

## 4. 学習順序：発見の喜びを残す

1. **2項の直接共通因子・発見型**：P11から始め、R0中心。L33/L44を使い、`4桁×4桁`を2回から1回にする価値を実感させる。題名で「共通因子をくくる」と明かさない。
2. **2項の位置と桁数を混合**：P11/P22/P12/P21を順次導入して混合。L33/L44を中心にしつつL22・L32・L43なども補助的に使用。
3. **R0中心にR1/R2を時々混ぜる**：10の倍数、10/100/1000の和は「ボーナス」。特別な和にしか工夫が役立たないという誤学習を避ける。
4. **K1：A4×A2の複合**：20×50、25×40、125×80等、くくる利益に追加の利益がある例を散りばめる。
5. **3項のうち2項のみ共通因子**：T12→T13/T23へ。**3回の乗算が2回になる**ことを発見する。共通でない1項を見分ける注意深さを育てる。
6. **3項すべての共通因子**：T123へ。**3回の乗算が1回になる**ことを、前の段階を踏まえて自発的に発見する。
7. **3項のT2/T3混合と自己点検**：初回答案→答え提示前の見直し、概算・別経路による確認。続いて将来、減算・隠れた共通因子（H1）・4項以上・工夫不要問題に展開。

**注意**：最初は工夫しない計算も可能な状況を残すが、時間を浪費させることが目的ではない。必要な支援は段階的に導入し、学生の自発的な別解を認める。

## 5. 問題バンクと試作PDFの原則

- 一人の学生が解く問題数と、**問題バンクの収録総数は別**。全分類の直積を強制せず、診断しやすい組合せを重点化。
- 問題データには**元の因子列（各項の掛け算）**、共通因子、共通項番号、対象因子の位置、R/K/L/H/S、正答、代表的な変形、診断タグを格納する。
- 問題生成時は、すべてのターゲット項が記録どおりの共通因子を含むこと、残りの和がR分類と一致すること、桁数・正答・ID・元の式の重複を機械検証する。
- 意図しない簡単な別解や、K0が意図せずA2的なボーナスになっていないか、教育的な確認も行う。
- PDFは「学生用」「解答・解説用」「教員用」を分離する。学生用の発見型ページはF/P/R/L等のコード・分類・種明かしを表示しない。各ページは独立した短いセットとして使える。
- 正答の検証は、直接計算による総和と、くくった積からの結果を**独立に照合**。自己点検用には答え提示前の修正欄を設ける。
- CBT/CBDの将来実装では、共通因子の発見、位置の認識、R/Kの扱い、3項中2項／3項全部の認識、見直しを区別して診断する。単問の正誤から原因を断定しない。

## 7. 保留事項
