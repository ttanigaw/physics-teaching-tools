# A4 初期問題バンク（292問）

**試作／未検証**。主な対象は15〜16歳。九九の単独問題は対象外。A4は数値計算において**分配法則を逆向きに使い、掛け算の回数を減らす**技能です。

## 問題バンクの内訳

| 分類 | 件数 |
|---|---:|
| 2項・基本の探索 | 32 |
| 2項・R1/R2のボーナス | 48 |
| 2項・A2との複合（K1） | 24 |
| **2項・減算（S1）** | **40** |
| 3項中2項に共通因子 | 60 |
| 3項すべてに共通因子・加算のみ | 56 |
| 3項すべてに共通因子・差を含む | 32 |
| **合計** | **292** |

R0（残る和が特別な数にならない問題）を中心に、L33/L44（元の掛け算の負荷が高く、各因子の桁が揃う問題）を十分扱います。2項→3項のうち2項だけ→3項全部、と学習順を進めます。

## データ

元の式は`terms`（例：`[[4387,2764],[3129,4387]]`）、共通因子は`common_factor`、その項位置は`common_terms`、項内位置は`shared_positions`です。構造の分類は`L`、`R`、`K`、`H`、`S`に記録します。整数・共通因子が直接見えるH0のみです。N2T12にも減算S1を導入しました。**S1はN2/N3を通して最後の項を引く**（N2は第2項、N3は第3項）、S2はN3で第2項を引くことを表します。残りの差で3/4桁から1/2桁になる例は `remainder_digits` と `cancellation_from_digits` に記録します。

`naive_multiplications`と`grouped_multiplications`は、分配法則を利用した場合の乗算回数の比較用の簡易指標です。教育的な実感や難易度を直接測ったものではありません。`discovery_difficulty`は現時点で未測定です。

ID例：`A4-N3T13-P12-L33-R0K0-H0S0-01`。**末尾2桁だけが同じ詳細パターンの数値違い**です。元の数式と正答を別々の計算経路で検査した問題を収録していますが、試用後に難度や解説を修正する可能性があります。

**v0.2の変更**：K0の一般問題は共通因子と残る因子の組を大幅に多様化（同じ共通因子の反復を抑止）。K1の20・25・125は**意図した反復**として保持する。加算だけだった3項T123にS1／S2の減算問題32問（差が1桁16問・2桁16問）を追加。既存の220問は分類IDを維持しながら数値を再生成したため、旧式との対応はGit履歴（v0.1）で確認する。

### 初歩問題の数値調整（v0.2.2）

- `A4-N2T12-P11-L32-R0K0-H0S0-01` は、2のべき乗の128と16という偶発的な一致を避け、`163×47+163×29` に変更。
- 同じ発見型の導入問題で共通因子が16だった問題も、59に変更。
- 加算のみの`S0`なのに負数の因子が現れていた17問を正の因子へ修正。分類ID・L・R・Pを保持。
- **IDの意味は[全問題一覧の冒頭](A4_ALL_PROBLEMS.md#仮idの命名規則)に記載**。数値の修正を再生成で失わないよう生成プログラムにも反映した。
- 試作プリント用の選択データは更新したが、**以前配布したPDF（v0.2）は旧数式を含む**ため、再生成してから使用する。

### v0.3：2項減算と和の桁数規則

- **N2の減算（S1）40問**を追加。P11/P12/P21/P22、L22/L32/L33/L43/L44を扱う。
- くくった括弧内で正の数を加算する場合、例えば2桁＋2桁の結果は2桁以内、または3桁なら**1の位が0**。3桁＋3桁でも同様（4桁になるなら1の位0）。4桁や3項の和にも同じ方針を適用。
- 桁上がりして1の位が0でなかった加算問題**72問**を、分類ID・R・Lを保ちながら再数値化。変更前の数式はGit履歴に残る。
- [全問題一覧](A4_ALL_PROBLEMS.md)の冒頭にN2/N3を通じたSコードの命名規則を掲載。
- PDF出題プランも11枚・88問へ変更。古いPDFは旧数値であることに注意。

## 再生成

`calculation-drills/`から：

```bash
node tools/make_a4_bank.mjs
node tools/make_a4_problem_list.mjs
node tools/make_a4_pdf_records.mjs
```

最後のコマンドは試作プリントに選んだ88問について、元のJSONと[出題プラン](../printable/a4_sample_plan.json)からTSVを再生成します。

**全員に292問解かせる設計ではありません。** 教材側の網羅と一人の学習者への出題数は別に扱います。個人の回答ログは公開GitHubに登録しません。
