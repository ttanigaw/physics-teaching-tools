# A2 初期問題バンク

- データ：[a2_bank.json](a2_bank.json)
- 生成・分類検証：[../tools/make_a2_bank.mjs](../tools/make_a2_bank.mjs)
- 試作プリントの選択：[../printable/a2_sample_plan.json](../printable/a2_sample_plan.json)

## 状態

**初期候補138問／draft／授業での効果・難易度は未検証**。設計書から継承した28候補に、F系列・倍率、2～4因子の位置と向き、D0/D1/D2/DB、複数組・対照問題を追加した。主対象15〜16歳のため、**九九（1〜9同士の掛け算）の単独問題3問を除外**した。F1Aは分類上残し、3因子以上で計算の工夫を練習する問題には利用する。全分類の直積を網羅した完成問題バンクではない。試作PDFで使用するのは42問。

## 基本データ

各問題のフィールド：

| キー | 内容 |
|---|---|
| `id` | 分類型ID。例：`A2-F2A-N3P13-D0-01` |
| `factors` | 元の式の因子（左から順）。小数は数値で保持 |
| `focus` | 先に組にするとよい2数の組。複数組の場合は複数列。対照問題は空列 |
| `answer` | 掛け算の厳密な結果（現時点の扱う数値で数値計算） |
| `phase` | 基礎・発見・転移・分解・選択の初期タグ。教材の掲載順は別管理 |
| `checks` | 自己点検方法の候補（M1、M4、M6等） |
| `description` | 教員向け作問意図 |
| `diagnostic_axes` | IDから取り出したF、NP、Dコード |
| `status` | draft。完成・授業利用を保証するものではない |

L1～L5などの学習形式は**問題そのものの固定属性ではない**。利用目的に合わせてプリント側やCBD側で決める。問題によっては複数の効率的な解法があるため、`focus`は代表的な設計意図であって唯一の解法ではない。

## 追加時の検証

生成スクリプトはIDの構造、因子数、Fの系列・倍率、Pの位置と向き、Dの分解対象と整数倍率、ID/式の重複、**九九のみの単独出題の禁止**を検査する。問題の数学的結果も計算しているが、**教育効果・発見難度・負担軽減の適切さは別途レビューする**。とくに自動生成したN4問題は紙面に採用する前に出題価値を見直す。

## 再生成

```bash
node tools/make_a2_bank.mjs
```

リポジトリの`calculation-drills/`をカレントディレクトリとして実行する。更新時には既存のIDを再採番しないこと、配布済みの問題との対応が維持されることを確認する。

将来的には、よくある誤答、ヒント段階、指導上の注意、難易度実測結果などのメタデータを充実させる。学生ごとの学習ログはここには保存しない。
